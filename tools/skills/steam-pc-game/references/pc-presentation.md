# PC 表现与平台隔离

## 布局与风格

- 营地是主界面，保留画面与入口，战斗只呈现当前战斗所需信息。更多屏幕空间不意味着增加常驻解释面板。
- 保留用户已认可的视觉语言：骰子、盾牌、治疗/力量药水用图标；库存和效果倍率分别绑定真实值。数量变化在原控件更新，不以长文字替代成熟图标。
- 桌面键鼠布局采用清晰主操作、悬停状态、稳定命中槽、快捷键及统一取消逻辑。模态窗口和 Overlay 打开时，底层键鼠遵守同一屏障。
- 背景构图预留敌我脚点、角色轮廓和 HUD；十二个地区与副本应有可识别地貌，不能靠同图换色冒充独立场景。不要把角色、数字和按钮烘焙进场景。
- 参考成功游戏时记录具体可迁移优点，不声称取得其专有代码或精确动效参数。采用本项目原创资产和既定玩法。

## 固定构图与高清字体

固定逻辑画布等比适配，剩余区域留边；窗口比例变化不能触发布局像网站一样重排。输入和画面使用同一套缩放/偏移变换。

固定布局不等于把低分辨率画布整体放大。分别记录原画像素、内部渲染像素、最终客户区物理像素及 DPI。背景按源尺寸采样；文字与边框在最终输出分辨率栅格化。缩放和 DPI 变化时更新字形缓存，不用截图放大或全屏模糊来隐藏锯齿。

本项目 Cocos 3.8 Windows 曾出现：浏览器描边有效，但原生 Canvas 的 strokeText 无实际输出。需检查当前引擎实现和实机结果；可使用少量偏移字形做轮廓，或采用已验证的字体渲染方案。不能把这个特定版本问题推广到所有引擎。战斗数字优先粗字、深色轮廓、足够对比和短促弹出；正常菜单文字不堆叠重阴影。

字体恢复与字体清晰度是两个问题：先确认字体族是否改变，再查渲染缩放、缓存、采样、过小字号。数字、中文及其他文字体系分别检查，不能用拉丁字形检查证明全语言正常。

## 连续战斗动画

- 起势→语义命中→回稳→装饰收尾。生命扣减、伤害数字和命中同拍；按事件快照播放，不用最终血差推测多段伤害。
- 攻击/受击方向面向对手，脚底和阴影保持接触关系，跳跃时阴影缩淡，死亡时停止待机及残留特效。整幅立绘大幅摆动、拉伸不是高质量骨骼动画。
- 原始立绘只有一层时，先采用克制的蓄力位移、姿态切换和命中特效；拆层、骨骼及逐帧适用于有相应资源的角色。不要写“全宠物骨骼动画”来描述程序位移。
- 控件实例保持稳定；入场视觉不接点击，重复物品用实例身份。动画回调绑定生命周期，切页取消旧动画；环境随机独立于玩法 RNG。
- 敌我骰子均展示真实候选点数，滚动动画最终落在模型确定结果；不让老虎机视觉改变概率或在未结算前显示未来状态。
- 普通悬停/按压约 80–160ms、补位约 120–240ms可作起点，不是行业达标参数。减少动态与快速模式保持相同规则结果。

## 最小实机检查

同一包体检查窄窗口、16:9、16:10、超宽、最大化/还原及高 DPI；用实际鼠标命中、一次快捷键、连续攻防、用药刷新和长语言确认。工具发出的键盘事件未进窗口时，用真实按键区分自动化限制，不立即重写输入系统。

PC 只读复用共享高清原画，PC 新资源保留在 pc/assets，手机压缩资源保持原路径。构建时复制合成，不能用链接或原地替换把 PC 改动回写手机源目录。
