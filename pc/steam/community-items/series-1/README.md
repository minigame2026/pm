# Dicekin — Steam 社区物品，系列 1

AppID 5500200。2026-10-26 制作并上传到 Steamworks 社区物品草稿：5张卡牌、5级普通徽章及闪亮徽章、5种表情、3张个人资料背景、1枚透明游戏标识。未提交物品审核、未发布，卡牌掉落尚未启用。

卡牌沿用游戏角色及已有译名：闪尾狐/Sparkfox、芽芽龙/Sproutling、潮泡獭/Bubbotter、星环鸮/Starowl、霆冠龙/Thundrake。人物原始设计参考项目 `art-source/runtime-masters-v1/`；卡面为重新生成的独立收藏插画，骰子融入场景。背景为个人资料专门构图，森林、海湾、星穹三主题，暗色边缘渐隐。徽章与表情为原创可编辑SVG。

`catalog.json` 保存英文、日文、韩文、繁中、简中文案、图片路径与源图像素。表情的实际Steam标题为唯一聊天代码，译文放在描述字段。`sources/`保留AI辅助原画；`cards/`与`backgrounds/`为1920×1080平台导出JPG（小于350000字节），源图为1672×941，导出放大不代表新增真实细节。小卡206×184；徽章80×80；表情18×18与54×54；标识206×44。

`preview-v2.png`可查看小卡与图标实际缩略效果。徽章ID1，卡牌2–6，背景7–9，表情10–14；再次上传前先读取对应条目，不重复创建。后台检查、账号截图与原始响应不进入公开GitHub。
