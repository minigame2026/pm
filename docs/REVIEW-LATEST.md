## 模块化复用

模块入口与检查路由已补入[模板复用指南](TEMPLATE-REUSE.md)：

- PMModel：玩法、个体、奖励与规则；迁移必须检查旧档。
- TrustedClock / DurableCheckpoint / PMRewardedAds / PMAudio：计时、持久化、平台广告、音频服务。
- PMGame：现有页面/交互；仍是较大文件，局部改动明确指定scope，不能描述成完全插件化框架。
- PMAppBattle + AppBattleArt：原生增强与姿态图，普通小游戏不自动加载整套增强。
- PMLocale + PMTranslations + LocalizedLogoArt：文字翻译与品牌图片分别管理。
- PMArt：共享加载/释放与缓存，业务模块声明资产键。

不在复盘时拆分全部代码；新功能优先沿既有边界复用，先做最小可测试样板再扩展。
