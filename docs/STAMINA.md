# 体力与地图探险

2026-10-20。地图作为一关：十二张地图每张10场。完成上一地图的最终巢穴结算后解锁下一地图，不能跳图。

- 新档及缺少体力字段的旧档初始化30点，上限30点。
- 每120秒恢复1点，离线经过的时间计入；未满时保留剩余秒数，满体力不积累额外恢复次数。
- 进入整张地图扣5点，从第1场开始。体力不足不进入、不扣费；战斗之间不再扣费。
- 刷新页面后继续同一次探险不重复扣费。主动点击右上角房屋图标回营地则结束探险，地图进度和临时强化清除，体力不退。
- 重新进入、失败后重试仍需5点。收藏、已领取的蛋、孵化任务、孵化能量和通关记录保留。
- 体力与战斗获得的孵化能量是不同资源。
- 体力槽下显示下一点体力恢复的 `MM:SS` 倒计时，满体力显示 `00:00`；未取得可信时间显示 `--:--`，无中文提示。

存档包含 `stamina: {value, updatedAt}` 和 `expedition`。规则函数在 PMModel.ts；营地头像、体力条与视频按钮在 PMGame.ts。采用[可信时间](TRUSTED-TIME.md)：联网校时后结算离线收益，校时失败暂缓，手机时间变化不参与收益计算。

通关或失败先显示结算页，唯一主要操作为“返回营地”。返回时结束本次探险并保留已获得的蛋、孵化能量和通关记录，不退体力；刷新后仍可看到尚未确认的结算。

## 激励广告接口

宿主可设置 `globalThis.pmRewardedAd`，提供：

```ts
interface RewardedAdBridge {
  show(request: { placement: 'stamina_10' | 'hatch_reduce_30m' }): Promise<{ completed: boolean }>;
}
```

平台适配层应展示真实激励视频，并且只在完整观看的关闭回调中返回 `{completed: true}`。取消返回 false；加载/播放失败拒绝 Promise。一次请求进行中禁止重复调用。

游戏只在完成结果后加10体力，并限制到30。没有适配器时显示“激励广告待接入，暂不能领取”，不会模拟发奖。接入微信/抖音时需填写真实广告位并在真机验证；本轮只预留接口。

孵化屋使用 `hatch_reduce_30m`：完整观看后为该蛋减少30分钟，最多减到当前可信时间，不消耗能量。取消/失败不生效；缺少适配器时提示暂不能加速。跨前后台校时失败时保存 `pendingHatchAd: {index, eggId}`，联网后只为相同蛋结算并清除待发记录。旧能量字段保留兼容存档，但孵化屋不再显示或消费。

验证：`checks/stamina.test.cjs`、`checks/stamina-runtime.cjs`；涵盖离线恢复、上限、读档、扣费与重复进入、体力不足、撤退、锁图、广告缺失/取消/完成，390×844与320×568已查看。战斗与地图已有规则测试通过，待用户试玩。
