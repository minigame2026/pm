## 实现

- `PMArt.ts`集中管理图片：封面只预载封面、标题、按钮。人物、宠物、背景、图标按实际展示请求；同一图集只发一个并发加载请求，瞬时失败最多尝试3次。
- 图鉴/伙伴等PageView仅加载当前可见页；滑动相邻页进入视野时加载。异步回调检查节点与绑定身份，避免快速翻页把旧图贴到新节点。
- 活跃图片保持引用；闲置4秒或缓存超过32MiB时回收最早未用纹理。**当前页/滑动相邻页仍会保留，32MiB不是绝对峰值限制。** 浏览全图鉴过程中测试瞬时缓存最高约57 MB；返回营地等待回收后，缓存和Cocos资产管理器均只剩3张图片、约8 MB纹理。
- `prepare-runtime-art.py`从保留原图产生缩小PNG；图标最长192px，初始头像512px，标题按钮768px，多数宠物图集1024px，场景/主角最高1152px。RGBA缩放后用PNG无损编码，不生成新的美术设计。
- 原图与来源尺寸在`art-source/runtime-masters-v1/`、`ArtSourceSizes.ts`。原图不属于assets，不进入构建。保留已有UUID，裁切矩形按尺寸换算，脚底归一化坐标不变。
