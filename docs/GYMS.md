# 道馆（当前入口）

2026-10-23。营地右侧“道馆”已替代旧四种训练师对战入口；探险在左。旧对战模块仅保留存档兼容，不作为当前玩家功能说明。

- 共9馆，分别通关对应1～9号探险地图后解锁；10～12号探险没有新增道馆。
- 每馆10战，第5层精英、第10层BOSS，均不进入偷蛋；通关后不可重打。
- 每馆覆盖指定两种属性的全部系列/形态，含好友和新神兽系列。目前每属性5系列，故每馆10系列、30形态。
- 新遭遇生命与攻击点数按原对应地图规则×1.5并取整，伤害再按当前属性克制计算。旧档已开始的遭遇不重写数值。
- 普通层R/SR/SSR为70%/25%/5%，第5层SR/SSR为80%/20%，第10层SSR。
- 通关获得对应徽章，自己的两种属性宠物永久最大生命、攻击各+10%。该加成在战斗派生，不写入遗传基础值。
- 队伍独立HP、自动替补、药水和技能复用探险规则；中断继续沿用现有保存。道馆不额外扣探险体力。

规则入口：`PMModel.GYMS/gymUnlocked/gymEnemyPool/enterGym/gymBonus`；界面：`PMGymsUI.ts`。具体属性组合以源码和自动表为准。当前规则检查覆盖每馆10系列/30形态及原始1.5倍率；浏览器与平台真机验证分别记录。
