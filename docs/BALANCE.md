# 数值、概率与结算规则

2026-10-20 当前实现。以 [PMModel.ts](../assets/scripts/PMModel.ts) 为执行依据；[完整表](generated/TABLES.md) 自动枚举 108 形态、6张地图共210层和全部技能。下列公式说明口径，非另一个配置源。

| 队伍 / 孵化位 / 交配任务 | 3 / 2 / 1 |
| 兼容能量字段 | 初值0、上限9999；旧状态保留，UI无能量消费入口 |
| 原18系列形态 HP 加值 | R +0，SR +2，SSR +4；自然攻击数组不随品质改变 |
| 新18系列形态成长 | R / SR / SSR 的HP加值为0 / 6 / 12，攻击数组每项加值为0 / 2 / 4；各品质采用不同技能 |

数组按**索引等概率**抽取。例如 `[3,3,4]` 中 3 的概率 2/3。随机状态为 32 位 LCG：`seed=(imul(seed,1664525)+1013904223)>>>0`，除以 `4294967296` 得 `[0,1)`。战斗/奖励/寻蛋用 `seed`；孵化/性别/遗传用独立 `hatchSeed`。都随存档保存，不是联网随机或防作弊系统。

治疗倍率：×1 50%、×2 40%、×3 10%，期望 1.6。力量倍率：×2 50%、×3 40%、×4 10%，期望 2.6。两项每回合独立抽；无保底、无累计修正。

## 战斗结算

最大生命 `maxHP = baseHP + hpBonus`。显示生命 `max(0, ceil(hpRatio * maxHP - 1e-8))`，内部保留比例，勿把显示取整反写成新存档规则。

1. 开始挑战初始化技能状态；抽攻击、治疗、敌攻和两种倍率；清除本回合药水使用标记。
2. 调整攻击点：防御蓄势的最高值 → 稳定发挥的最低改中位数 → 连锁电流的连续相同改最高；记录调整后的点数。
3. 治疗基础值为 `治疗点数 × 治疗倍率`，草木祝福再加 2。先处理药水消耗 / 返还和溢出护盾，生命封顶。UI 药水公式显示基础值，不包含所有被动加成。
4. 力量共鸣先把攻击改为最高点，再使用力量倍率。直接伤害为 `max(1, round(攻击点数 × (已用力量 ? 力量倍率 : 1) × 属性倍率)) + 抢先一击2 + 第三次攻击重击4`。固定加伤不乘倍率，实际直接伤害不超过敌人剩余 HP。
5. 攻击触发施毒、压制、吸血等；防御触发下回合最高与护盾。毒每次攻击 / 防御行动结尾扣 2，共最多三次；施毒的本次行动即第一次，药水不推进毒。
6. 敌人归零立即结算胜利，不反击。普通 / 精英 / BOSS 分别 +1 / +2 / +3 能量。
7. 敌人存活：先算 `入射伤害=max(1, round(敌攻×敌对我属性倍率))`；攻击反击伤害为 `max(1, 入射伤害-本次霜羽压制2)`；防御为 `max(1, round(入射伤害×0.01))`。再处理硬壳减 2 至少 1 → 幻影免伤 → 护盾抵消。最终可因技能为 0。
8. 扣血后仍存活且生命比例 ≤30%，生命绽放可恢复 `ceil(maxHP×25%)`；死亡不能复活。否则继续下一回合重新掷点。

每个不同技能每场至多触发一次，持续效果按自己的次数继续。技能列表见自动表；生命汲取为实际直接伤害的 20% 向上取整，上限 `ceil(maxHP×25%)`，不包含毒伤。护盾累计、剩余毒次数、下一回合最高均保存在状态中。

## 地图与敌人

属性关系使用宝可梦第六世代以后的18属性单属性表，来源：https://ph.portal-pokemon.com/game/type-chart/ 。本游戏克制×1.5、正常×1、抵抗×0.75、原完全免疫改为强抵抗×0.5；敌我各方向独立查询，不按反向取倒数。36系列/108形态沿用系列原属性，普攻取自身属性，无双属性与额外同属性攻击加成。治疗、毒伤、固定技能加伤及护盾不乘克制，吸血按实际直接伤害计算。相同规则适用于普通、精英、BOSS，不改变抽骰概率、奖励与存档结构。选敌上下点数展示当前对位的属性修正值；战斗攻击按钮大字为预计直接伤害，小字保留原始骰子点数。

地图 ID 从 0 开始：草叶海岸10、熔岩山径20、霜月雪原30、翠风群岛40、赤雷荒原50、星渊圣域60层。整张地图为一个大关，依次通关解锁；入场仍消耗5体力。每图配置六个独有系列，前四为普通池，第五为精英，第六为BOSS。层数逢5且不逢10为精英，逢10为BOSS，其余普通。普通池均匀选取；刷新尽量排除当前系列。

敌方品质：

| 地图 | R | SR | SSR |
|---|---|---|---|
| 草叶海岸 | 1–4 | 5–9 | 10 |
| 熔岩山径 | 1–5 | 6–14 | 15–20 |
| 霜月雪原 | 无 | 1–10 | 11–30 |
| 翠风群岛 | 无 | 1–10 | 11–40 |
| 赤雷荒原 | 无 | 1–10 | 11–50 |
| 星渊圣域 | 无 | 1–10 | 11–60 |

设关卡 `s`、地图 `m`、品质倍率 `q=R:1, SR:1.1, SSR:1.2`：

- 前十关基础 HP 为 `[7,9,11,14,24,20,23,26,29,48]`；之后普通为 `round(29/9×s)`，精英与 BOSS 为 `round(4.8×s)`。
- 敌人 HP = `round((基础HP + m×(8+floor(s×0.6)))×q)`；与该系列我方可用基础 HP 无关。
- 攻击数组 = 该系列 `enemyFaces` 每项 + 成长阶 + `2m` + 品质增量（R 0、SR 1、SSR 2）。
- 普通成长阶：1–3 为 0、4–6 为 1、7–10 为 2、11 起 `floor((s-1)/3)`。
- 精英 / BOSS 前十关成长阶 0；之后分别 `floor((s-5)/5)×2` / `floor((s-10)/5)×2`。

210层逐敌人数组已展开到自动表；普通关不能用某一只敌人的点数代表整池。难度系数随图与层增加，但关卡类型切换不保证每层HP严格递增；当前不是经过用户全程平衡验收的曲线。新地图自然R宠物的普通/精英/BOSS基础HP：第四关34/38/42、第五关44/48/52、第六关56/60/64；普通攻击数组分别为[4,7,10]、[6,10,14]、[9,13,18]，精英每项+1、BOSS每项+2。高品质形态再应用上表加值。原有个体及遗传个体保留存档中的属性。

## 战利品

选敌时生成一项奖励，切宠、进战斗、重载不改变；刷新敌人会重抽。类型从 HP、攻击点数、治疗点数、治疗药水、力量药水中均匀抽取，排除上一项已结算奖励类型，以及库存已达 9 的药水类型。因此不是固定每类 20%。

| 类型 | 值与选择 |
|---|---|
| HP 上限 | +3 概率 75%，+5 概率 25%；先保持绝对生命，再执行战后恢复 |
| 药水 | +1 概率 75%，+2 概率 25%；封顶 9 |
| 攻击数组 | 三选池 `[2,3,5] / [3,3,4] / [1,2,7]` 等概率，再每项加奖励阶 |
| 治疗数组 | 三选池 `[3,5,7] / [4,4,6] / [2,3,9]` 等概率，再每项加奖励阶 |

奖励阶：1–3关为0，4–6为2，7–10为4，11起 `floor((s-1)/3)×2`，再加地图 ID×2。数组奖励是**整组替换或维持旧组**的二选一，不是从新数组选择一个数，也不是新旧相加。当前数组长度为3，运行时兼容最多5项。

普通与精英奖励处理后恢复 `max(1, floor(maxHP×20%))`，生命封顶。精英随后寻蛋。**当前 BOSS 直接进入寻蛋，不领取此类战利品，也不经过这次20%恢复**，不可写成每场胜利都恢复。

## 巢穴与孵化

精英翻找上限2，BOSS3；每次独立抽蛋品质，系列从当前地图全部6个系列均匀抽。只带走一枚；次数用完默认最高品质，同档取第一个。没有“后一次保证更好”。

各检查点蛋概率见 [自动表](generated/TABLES.md)。表内为**单次翻找**概率；若用尽 n 次并总选最高，至少一枚 SSR 概率 `1-(1-pSSR)^n`，最高为 R 概率 `pR^n`，最高为 SR 概率 `(pR+pSR)^n-pR^n`。同一地图内所有精英共享精英概率，所有 BOSS 共享 BOSS 概率，不再随检查点递增。

| 大关卡 | 精英 R / SR / SSR | BOSS R / SR / SSR |
|---|---|---|
| 草叶海岸 | 95% / 5% / 0% | 90% / 9% / 1% |
| 熔岩山径 | 90% / 10% / 0% | 75% / 20% / 5% |
| 霜月雪原 | 84% / 15% / 1% | 70% / 20% / 10% |
| 翠风群岛 | 80% / 18% / 2% | 60% / 25% / 15% |
| 赤雷荒原 | 75% / 22% / 3% | 50% / 30% / 20% |
| 星渊圣域 | 70% / 26% / 4% | 40% / 35% / 25% |

每枚孵化基础30分钟，小晴24分钟；完整观看一次激励视频减少30分钟，不能早于当前可信时刻，不再使用能量加速。普通孵化品质转化如下，结果放入槽位即确定：

| 蛋 | 孵 R | 孵 SR | 孵 SSR |
|---|---:|---:|---:|
| R | 90% | 9% | 1% |
| SR | 0% | 95% | 5% |
| SSR | 0% | 0% | 100% |

系列保持蛋的 affinity；自然个体使用对应品质基础 HP 和一个技能。性别在领取时随机，雌雄各50%。领取后先保存，再揭晓；`hatchedEggIds` 防止重复领取，`pendingHatch` 支持刷新后再次显示未确认结果。重复个体正常保留，不返能量。交配蛋和结缘蛋品质固定，**不使用上表升品质概率**。

## 交配遗传

任意已拥有的一雌一雄，允许跨属性、跨品质，UID 必须不同。并行1任务，30分钟后领取蛋，领取时永久移除父母，蛋还需孵化30分钟。未领取前父母仍存在；模型未额外禁止其上阵。战斗中或有未确认孵化揭晓时不能领取交配蛋。

开始交配即独立决定三组遗传：形态＋品质50%随母 / 父；基础 HP 50%随母 / 父；整组基础攻击点数50%随母 / 父。技能先合并去重，再按下表决定数量，从池中均匀不放回抽；顺序不代表技能优先级。超过6种的池使用6档分布，上限6，不截掉父母技能候选池。

| 去重后的候选技能数 | 子代技能数概率 |
|---:|---|
| 1 | 1个100% |
| 2 | 1个50%，2个50% |
| 3 | 2个50%，3个50% |
| 4 | 2个30%，3个40%，4个30% |
| 5 | 2个20%，3个30%，4个30%，5个20% |
| 6及以上 | 3个20%，4个30%，5个30%，6个20% |

形态属于哪个系列就显示哪个属性，当前没有另一个可独立遗传的“属性类型”字段。治疗点数组属于探险状态，不是个体遗传项。临时 HP 加成与升级后的本局攻击不遗传。父母被移除后自动清理队伍和本局个体缓存；全空时需等孵化才能探险。

## 好友来访与结缘

一个当前访客，导入非本人来访码。互动3次，每次间隔至少2.5秒，首次也需等待；解锁的是系列，每系列只记录一条结缘。重复码不重复重置，同系列已解锁直接完成互动。

结缘用自己的可用蛋＋空孵化位，目标系列来自已解锁结缘记录。未解锁地图的系列只能用 R 蛋；SR/SSR 蛋要求目标地图已开放。结缘保留自己蛋的品质，不复制访客品质/属性数值/技能，也不消耗访客。普通蛋按目标系列自然基因孵化；交配蛋只改系列，保留自己的遗传 HP、攻击、技能。一次结缘记录可用于多枚自己的蛋，当前无每日次数或消耗结缘点数。
