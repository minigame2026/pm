# 数值、概率与结算规则

2026-10-21 当前实现。以 [PMModel.ts](../assets/scripts/PMModel.ts) 为执行依据；[完整表](generated/TABLES.md) 自动枚举 162 形态、9张地图共90层和全部技能。下列公式说明口径，非另一个配置源。

## 基础量与随机

| 项目 | 当前值 |
|---|---|
| 初始队伍 | 火/草/水三选一，只获得选中R个体；见 [初始流程](ONBOARDING.md) |
| 体力初值 / 上限 / 恢复 | 30 / 30 / 每120秒+1；整张地图入场−5；广告完整观看+10，见 [体力规则](STAMINA.md) |
| 初始治疗 / 力量药水 | 3 / 2；各库存上限 9 |
| 初始治疗点数组 | 3、5、7 |
| HP 加成 / 生命比例 | 0 / 100% |
| 刷新敌人 | 每场普通/精英遭遇免费1次，用完后每完整观看1次激励视频立即再刷新1次；BOSS不可刷新；不消耗药水。旧存档剩余2/1/0次分别迁移为1/0/0次，重载不补发 |
| 队伍 / 孵化位 / 交配任务 | 3 / 2 / 1 |
| 兼容能量字段 | 初值0、上限9999；旧状态保留，UI无能量消费入口 |
| 原18系列形态 HP 加值 | R +0，SR +2，SSR +4；自然攻击数组不随品质改变 |
| 第4～9关新增36系列形态成长 | R / SR / SSR 的HP加值为0 / 6 / 12，攻击数组每项加值为0 / 2 / 4；各品质采用不同技能 |

数组按**索引等概率**抽取。例如 `[3,3,4]` 中 3 的概率 2/3。随机状态为 32 位 LCG：`seed=(imul(seed,1664525)+1013904223)>>>0`，除以 `4294967296` 得 `[0,1)`。战斗/奖励/寻蛋用 `seed`；孵化/性别/遗传用独立 `hatchSeed`。都随存档保存，不是联网随机或防作弊系统。

治疗倍率：×1 50%、×2 40%、×3 10%，期望 1.6。力量倍率：×2 50%、×3 40%、×4 10%，期望 2.6。两项每回合独立抽；无保底、无累计修正。

## 战斗结算

最大生命 `maxHP = round((baseHP + hpBonus) × 巨化倍率)`（常态1、巨化1.5）。显示生命 `max(0, ceil(hpRatio * maxHP - 1e-8))`，内部保留比例，勿把显示取整反写成新存档规则。

以上生命比例和HP加成按宠物UID独立保存于 `combatVitals`，本局攻击点数按UID保存在 `runRoster`；顶层hpRatio/hpBonus仅为当前出战个体的兼容镜像。换宠保存旧个体并读取新个体数值，不治疗、不复制成长。HP上限、最低攻击+1、最高攻击+1奖励发给领取时的出战及两名候补；攻击数组替换、战后20%治疗仍只影响当前出战个体。药水库存/治疗点数仍全队共享。旧共享存档的生命比例与HP加成归当前出战宠物，候补以自身基础生命开始。

出战HP归零后按候补位置顺序查找存活且未交配的队员接替；无可战候补才失败。敌方本轮只攻击一次，换入队员开始下一回合并独立启用自己的技能；敌人已有毒状态、主角每场首次治疗消耗状态保留。阵亡记录持续到本次探险结束或触发复活奇遇；新探险全部恢复、清空本局成长。

1. 开始挑战初始化技能状态；抽攻击、治疗、敌攻和两种倍率；清除本回合药水使用标记。
2. 调整攻击点：防御蓄势的最高值 → 稳定发挥的最低改中位数 → 连锁电流的连续相同改最高；记录调整后的点数。
3. 治疗基础值为 `治疗点数 × 治疗倍率`，草木祝福再加 2。先处理药水消耗 / 返还和溢出护盾，生命封顶。UI 药水公式显示基础值，不包含所有被动加成。
4. 力量共鸣先把攻击改为最高点，再使用力量倍率。直接伤害为 `max(1, round(攻击点数 × (已用力量 ? 力量倍率 : 1) × 属性倍率)) + 抢先一击2 + 第三次攻击重击4`。固定加伤不乘倍率，实际直接伤害不超过敌人剩余 HP。
5. 攻击触发施毒、压制、吸血等；防御触发下回合最高与护盾。毒每次攻击 / 防御行动结尾扣 2，共最多三次；施毒的本次行动即第一次，药水不推进毒。
6. 敌人归零立即结算胜利，不反击。普通 / 精英 / BOSS 分别 +1 / +2 / +3 能量。
7. 敌人存活：先算 `入射伤害=max(1, round(敌攻×敌对我属性倍率))`；攻击反击伤害为 `max(1, 入射伤害-本次霜羽压制2)`；防御为 `max(1, round(入射伤害×0.01))`。再处理硬壳减 2 至少 1 → 幻影免伤 → 护盾抵消。最终可因技能为 0。
8. 扣血后仍存活且生命比例 ≤30%，生命绽放可恢复 `ceil(maxHP×25%)`；死亡不能复活。否则继续下一回合重新掷点。

每个不同技能每场至多触发一次，持续效果按自己的次数继续。技能列表见自动表；生命汲取为实际直接伤害的 20% 向上取整，上限 `ceil(maxHP×25%)`，不包含毒伤。护盾累计、剩余毒次数、下一回合最高均保存在状态中。

## 地图与敌人

属性关系使用宝可梦第六世代以后的18属性单属性表，来源：https://ph.portal-pokemon.com/game/type-chart/ 。本游戏克制×1.5、正常×1、抵抗×0.75、原完全免疫改为强抵抗×0.5；敌我各方向独立查询，不按反向取倒数。54系列/162形态沿用系列原属性，普攻取自身属性，无双属性与额外同属性攻击加成。治疗、毒伤、固定技能加伤及护盾不乘克制，吸血按实际直接伤害计算。相同规则适用于普通、精英、BOSS，不改变抽骰概率、奖励与存档结构。选敌上下点数展示当前对位的属性修正值；战斗攻击按钮大字为预计直接伤害，小字保留原始骰子点数。

地图 ID 从 0 开始：九张地图统一为10层。整张地图为一个大关，依次通关解锁；入场仍消耗5体力。每图配置六个独有系列，前四为普通池，第五为精英，第六为BOSS。层数逢5且不逢10为精英，逢10为BOSS，其余普通。普通池均匀选取；刷新尽量排除当前系列。

敌方品质随地图和层数由 `encounterRarity` 决定。九图每图仅10层；当前每层品质与实际HP、攻击数组统一查[自动数据表](generated/TABLES.md)，不再保留旧20～90层品质表。

设关卡 `s`、地图 `m`、品质倍率 `q=R:1, SR:1.1, SSR:1.2`：

- 前十关基础 HP 为 `[7,9,11,14,24,20,23,26,29,48]`；之后普通为 `round(29/9×s)`，精英与 BOSS 为 `round(4.8×s)`。
- 敌人 HP = `round((基础HP + m×(8+floor(s×0.6)))×q)`；与该系列我方可用基础 HP 无关。
- 攻击数组 = 该系列 `enemyFaces` 每项 + 成长阶 + `2m` + 品质增量（R 0、SR 1、SSR 2）。
- 普通成长阶：1–3 为 0、4–6 为 1、7–10 为 2、11 起 `floor((s-1)/3)`。
- 精英 / BOSS 前十关成长阶 0；之后分别 `floor((s-5)/5)×2` / `floor((s-10)/5)×2`。

90层逐敌人数组已展开到自动表；普通关不能用某一只敌人的点数代表整池。难度系数随图与层增加，但关卡类型切换不保证每层HP严格递增；当前不是经过用户全程平衡验收的曲线。新地图自然R宠物的普通/精英/BOSS基础HP：第四关34/38/42、第五关44/48/52、第六关56/60/64；普通攻击数组分别为[4,7,10]、[6,10,14]、[9,13,18]，精英每项+1、BOSS每项+2。高品质形态再应用上表加值。第7～9关成长和蛋概率见[扩展规则](REGIONS-7-9.md)。原有个体及遗传个体保留存档中的属性。

## 战利品

选敌时生成一项奖励，切宠、进战斗、重载不改变；刷新敌人会重抽。类型从 HP、攻击点数、治疗点数、治疗药水、力量药水、最低攻击+1、最高攻击+1中均匀抽取，排除上一项已结算奖励类型，以及库存已达 9 的药水类型。

| 类型 | 值与选择 |
|---|---|
| HP 上限 | +3 概率 75%，+5 概率 25%；全队上限增加，保持原有绝对生命；出战者另执行战后恢复 |
| 最低攻击 | 全队各自当前攻击数组中所有等于最低值的项+1 |
| 最高攻击 | 全队各自当前攻击数组中所有等于最高值的项+1 |
| 药水 | +1 概率 75%，+2 概率 25%；封顶 9 |
| 攻击数组 | 三选池 `[2,3,5] / [3,3,4] / [1,2,7]` 等概率，再每项加奖励阶 |
| 治疗数组 | 三选池 `[3,5,7] / [4,4,6] / [2,3,9]` 等概率，再每项加奖励阶 |

奖励阶：1–3关为0，4–6为2，7–10为4，11起 `floor((s-1)/3)×2`，再加地图 ID×2。数组奖励是**整组替换或维持旧组**的二选一，不是从新数组选择一个数，也不是新旧相加。当前数组长度为3，运行时兼容最多5项。

全队奖励不涉及收藏中未编队或交配中的宠物；阵亡候补同样增加上限/攻击，但不复活。成长仅本次探险有效，不写入自然基因，不遗传；攻击点数封顶100，HP加成封顶450。最低/最高并列时各项同时+1（如 `[2,2,5]` 最低+1变为 `[3,3,5]`）。

普通与精英奖励处理后恢复 `max(1, floor(maxHP×20%))`，生命封顶。精英随后寻蛋。**当前 BOSS 直接进入寻蛋，不领取此类战利品，也不经过这次20%恢复**，不可写成每场胜利都恢复。

## 巢穴与孵化

精英翻找上限2，BOSS3；每次独立抽蛋品质，系列从当前地图全部6个系列均匀抽。只带走一枚；次数用完默认最高品质，同档取第一个。没有“后一次保证更好”。

各检查点蛋概率见 [自动表](generated/TABLES.md)。表内为**单次翻找**概率；若用尽 n 次并总选最高，至少一枚 SSR 概率 `1-(1-pSSR)^n`，最高为 R 概率 `pR^n`，最高为 SR 概率 `(pR+pSR)^n-pR^n`。同一地图内所有精英共享精英概率，所有 BOSS 共享 BOSS 概率，不再随检查点递增。

| 大关卡 | 精英 R / SR / SSR | BOSS R / SR / SSR |
|---|---|---|
| 草叶海岸 | 95% / 5% / 0% | 90% / 9% / 1% |
| 熔岩山径 | 90% / 10% / 0% | 75% / 20% / 5% |
| 霜月雪原 | 84% / 15% / 1% | 70% / 20% / 10% |
| 翠风群岛 | 80% / 18% / 2% | 60% / 25% / 15% |
| 赤雷荒原 | 75% / 22% / 3% | 50% / 30% / 20% |

每枚孵化基础30分钟，小晴24分钟；完整观看一次激励视频减少30分钟，不能早于当前可信时刻，不再使用能量加速。普通孵化品质转化如下，结果放入槽位即确定：

| 蛋 | 孵 R | 孵 SR | 孵 SSR |
|---|---:|---:|---:|
| R | 90% | 9% | 1% |
| SR | 0% | 95% | 5% |
| SSR | 0% | 0% | 100% |

系列保持蛋的 affinity；自然个体使用对应品质基础 HP 和一个技能。性别在领取时随机，雌雄各50%。领取后先保存，再揭晓；`hatchedEggIds` 防止重复领取，`pendingHatch` 支持刷新后再次显示未确认结果。重复个体正常保留，不返能量。交配蛋和结缘蛋品质固定，**不使用上表升品质概率**。

## 技能差异化与战后奇遇（2026-10-21）

自然技能为18属性×R/SR/SSR共54种；同属性同品质的不同系列共享对应技能。触发覆盖攻击、药水、防御、受击和掷骰，条件包括血量、点数、攻击次数、克制等，54种配置互不相同。每种技能每场一次；旧16种技能继续兼容已有遗传个体。旧自然单技能迁移为对应新技能，已记录遗传基因和多技能组合保留。完整名称与数值见[自动表](generated/TABLES.md)。上方旧技能名称描述的是保留兼容路径；新技能统一经SKILL_SPECS执行，固定加伤不乘属性倍率。

新技能的治疗/吸血向上取整，按各自配置恢复，生命封顶；护盾可叠加，免伤可为0，减伤至少1，不屈在护盾与减伤后判定致命并留1HP；印记持续3次，每次2/4/5/6伤害按技能取值。同场多次施毒刷新3次并保留较大伤害。巨化倍率参与基础攻击及力量倍率结算，固定技能加伤保持固定。

第1/2/3/4/6/7/8/9层胜利并处理原奖励、20%战后治疗后，以20%总概率发生一次奇遇；5层精英和10层BOSS仍走寻蛋。发生时在当前有有效目标的事件中等概率选一种，无效事件不参与抽取：

| 事件 | 效果 |
|---|---|
| 复活 | 随机一名阵亡队员，恢复满生命 |
| 治疗 | 存活且受伤队员中当前HP数值最低者回满；并列随机，不复活 |
| 巨化 | 随机一名未巨化的存活队员，立绘、最大HP、基础攻击×1.5；生命比例保留，持续接下来2场且不越过本关末层，不叠加 |
| 招式学习器 | 随机存活队员学会一种尚未拥有的临时招式，共8种；本关结束或撤退清除 |
| 精英蛋 | 按当前地图第5层精英的R/SR/SSR概率生成1枚蛋，系列取当前地图6系列池，直接入蛋袋 |

8种临时招式：攻击回血4、防御回血6、力量药水护盾5、生命药水使下次骰点最大、敌半血攻击加伤5、致命留1HP、首次掷骰护盾4、第三次攻击回血5。各自每场一次。临时技能独立于最多6个永久遗传技能，单只本关最多获得8种不重复招式；不参与交配技能池。

奇遇效果先应用并保存，再显示结果页；继续按钮只前进，不重复发奖。runEffects按UID存储巨化到期层和临时招式；换宠/自动替补/读档保留，新探险重置。巨化到期恢复原上限且保留生命比例，HP奖励与基因保持独立。

## 交配遗传

任意已拥有且非出战的一雌一雄，允许跨属性、跨品质，UID 必须不同。并行1任务，30分钟后领取蛋，领取时永久移除父母，蛋还需孵化30分钟。开始交配后父母从伙伴列表和候补隐藏且不能编入队伍，交配屋仍可查看。战斗中或有未确认孵化揭晓时不能领取交配蛋。

开始交配即决定三组遗传：异品质时形态＋品质固定随较高品质一方；同品质时形态50%随母 / 父。无论品质是否相同，基础 HP、整组基础攻击点数各自独立50%随母 / 父。既有交配任务和蛋不重抽。技能先合并去重，再按下表决定数量，从池中均匀不放回抽；顺序不代表技能优先级。超过6种的池使用6档分布，上限6，不截掉父母技能候选池。

| 去重后的候选技能数 | 子代技能数概率 |
|---:|---|
| 1 | 1个100% |
| 2 | 2个100% |
| 3 | 2个50%，3个50% |
| 4 | 2个25%，3个50%，4个25% |
| 5 | 3个25%，4个50%，5个25% |
| 6及以上 | 4个25%，5个50%，6个25% |

形态属于哪个系列就显示哪个属性，当前没有另一个可独立遗传的“属性类型”字段。治疗点数组属于探险状态，不是个体遗传项。临时 HP 加成与升级后的本局攻击不遗传。父母被移除后自动清理队伍和本局个体缓存；全空时需等孵化才能探险。

## 六类惊喜（2026-10-21首版）

各类使用独立于战斗/遗传抽样的持久化随机流，失败累计递增；命中清零，保底次数含本次。规则集中在 `SURPRISE_RULES`，不是恒定概率。

| 类型 | 初始概率 | 每失败一次增加 | 概率上限 | 最迟触发 |
|---|---:|---:|---:|---:|
| 金色骰子 | 4% | 0.2个百分点 | 15% | 第50次回合掷骰 |
| 神秘敌人 | 8% | 0.4个百分点 | 20% | 第20次遭遇生成 |
| 异色 | 2% | 0.2个百分点 | 12% | 第50枚支持异色的蛋 |
| 蛋中蛋 | 5% | 0.5个百分点 | 20% | 第25枚非赠送蛋 |
| 技能共鸣 | 12% | 1个百分点 | 30% | 第10次满足共鸣组合的合成 |

- **金色骰子**：实际探险每回合掷骰判定，三效果等概率：本回合基础攻击×1.5（与力量药水、巨化相乘，固定伤害技能不加倍）；存活队员各恢复最大HP的15%向上取整；出战宠物护盾+6。不会复活阵亡队员；护盾总量封顶200。无需新增按钮。
- **神秘敌人**：遭遇生成（含刷新）时决定，战前显示“?”，开战揭晓。三种等概率：巨兽HP×1.4向上取整、攻击×1.2、立绘×1.3；幻影每逢第3/6/9…回合攻击×1.4；护盾初始吸收最大HP的25%向上取整，毒绕过盾。胜利时普通掉落外追加当前地图随机系列R蛋一枚，唯一ID防重复。强度不改变原地图的精英/BOSS蛋概率。
- **异色**：`SHINY_PETS`暂为9地图各首个系列，包含各系列R/SR/SSR共27形态；浅金配色与星光表现，品质/数值不加成。开始孵化时确定，已有孵化位不补抽。其他系列暂不参与异色计数。
- **蛋中蛋**：开始孵化时确定，破壳领取宠物时同时放入额外R蛋；来自原蛋所属地图，交配蛋采用形态所属地图。额外蛋带`nested`标记，不会再产蛋中蛋，可正常孵化/异色，不降低原蛋或宠物品质。
- **秘密配方**：火＋水→蒸汽之约；草＋电→萤光之约；幽灵＋妖精→月影之约。每次匹配父母属性必得对应装饰，领取交配蛋后登记配方；孵出宠物显示蒸汽/光点/月影环。配方入口在交配屋底部；不影响品质、HP或技能数量。
- **技能共鸣**：在正常遗传技能已抽取后，匹配恢复/汲取＋护盾/减伤、毒＋汲取/增伤、最高点数＋护盾/减伤三组，再判定概率；符合多组时等概率选一组，升级其中一个已继承技能，保留技能总数与上限6。共鸣技能可继承，但不再作为升级原料。每场一次：花盾（使用生命药水时额外HP+4及盾+4）、蚀魂（攻击时汲取实际伤害25%向上取整，并施毒3次每次3）、蓄壁（防御时盾+5且下回合最高点数）。

随机结果先进入现有可靠存档再显示动画；再次进入沿用结果，不能通过重开重抽，重复领取不重复发放。计时仍复用可信时钟，正式30分钟不变。以上为首版设计值，尚未实测长期平衡与用户体验；客户端存档机制不等于防篡改安全服务。

## 好友来访与结缘

一个当前访客，导入非本人PMV1/PMV2码或明信片图片。一次共同掷骰即保存结缘与合影；首次展示8秒，后续2秒，可跳过，不影响已保存结果。旧三次互动进度兼容；同来访者同系列不重复发放合影，最新12条通信记录不影响已解锁系列。详见[通信小屋](SOCIAL-POSTCARDS.md)。

结缘用自己的可用蛋＋空孵化位，目标系列来自已解锁结缘记录。未解锁地图的系列只能用 R 蛋；SR/SSR 蛋要求目标地图已开放。结缘保留自己蛋的品质，不复制访客品质/属性数值/技能，也不消耗访客。普通蛋按目标系列自然基因孵化；交配蛋只改系列，保留自己的遗传 HP、攻击、技能。一次结缘记录可用于多枚自己的蛋，当前无每日次数或消耗结缘点数。
