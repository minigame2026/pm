## 对照方法与边界

同一份当前生产模型加载两套VM：旧池只截取原5事件/8临时技能，新池使用20事件/32临时技能，其余现有数值、合法目标筛选和20%触发门槛均相同。不是拿旧版本整套难度作比较。

使用 simulate-balance.cjs 现有可见点数策略：属性配队与换宠、治疗、强化、坏点防御、比较奖励，不预知随机数，不看广告，不反复重抽同一蛋。每对使用相同起点/初始种子/可信时间/策略；事件分支消耗随机数不同，后续敌人与骰子可自然分叉。

较弱组是上一地图首次通关并正常养成后的队伍（第1图为新档单初始宠）；已通关养成组是本图首次通关并孵化/交配后的队伍，不代表毕业队。1–9图复用两批历史生产模型成长快照；10–12图从6条第9图快照经生产战斗、孵化、交配继续养成，6条都完成第12图，无注入宠物、数值或解锁。

首轮12图×2组×25配对＝600整关/版本，五批种子。对初筛波动最大的4组分别补125对至150；第12图已通关养成组另补350对至500。共1450整关/版本、2900次配对版本运行，另有80次后期检查点养成探险。定向补测独立报告，不混入600次等权总体平均，以免选择偏倚。

区间为固定模拟策略/快照条件下配对差值的近似95%区间，并非真实玩家人群区间；小样本、同一成长来源和策略偏好会限制推广。绝对通关率不代表新玩家留存，也不是“所有人只有这么低概率通关”。
