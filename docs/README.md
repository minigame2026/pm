## 当前内容规模

- 18 个属性系列，每系列 R / SR / SSR 三种独立形态，共 54 种；每只拥有的宠物另有 UID、性别、基础属性与技能，可重复。
- 3 张地图，共 60 关：草叶海岸 10、熔岩山径 20、霜月雪原 30。
- 探险战斗、单项掉落、点数二选一、巢穴寻蛋、双槽离线孵化、拖动编队、消耗父母的交配、离线好友来访与结缘孵化。
- 当前运行目标是 **web-mobile 浏览器原型**。试玩入口：[本机游戏](http://127.0.0.1:8780/)。

## 维护约定

1. 新需求以用户最新决定为准；现状说明以当前源码为准。两者冲突时写明差异，不通过文档悄悄改变需求或行为。
2. 数值修改源头是 `assets/scripts/PMModel.ts`。自动数据和表格是只读快照，不是游戏读取的配置；不要只改文档期待游戏生效。
3. 更新源码后运行 `node tools/export-design-data.cjs`；核对是否需要同步本文档中的规则解释。`--check` 检查快照是否过期，不写文件。
4. `PROJECT.md` 保持短小；规则、资产与表格分别维护，日志和截图留在 `checks/`。不用每次任务读完整资料。
5. 技术测试、画面检查、用户验收、平台验收分别记录；文档更新时间不等于测试重新执行时间。
