# 初始流程 v0.12.0

2026-10-19。当前首次开局规则以本文和 PMModel.ts 为准，替代旧文档的“直接进入营地、默认两只伙伴”。

流程：骰子与宠物封面 → 开始游戏 → 选择主角 → 选择一只初始伙伴 → 营地。封面只有开始游戏按钮；这是单机入口，没有账号登录服务。

| 主角 | 性别 | 独有效果 |
|---|---|---|
| 阿岚 | 男 | 领取巢穴蛋时，20%概率额外获得一枚蛋；额外蛋按当前地图和关卡概率生成 |
| 小晴 | 女 | 新开始的孵化缩短20%，基础30分钟变为24分钟；不改变正在孵化的任务 |
| 星遥 | 女 | 每场战斗首次使用生命药水额外恢复3点，可与宠物技能联动 |

初始伙伴三选一：闪尾狐（火）、芽芽龙（草）、潮泡獭（水）。仅获得选中的一只R品质个体，性别等概率随机；之后获得新宠物仍走孵化。

每一步确认后存档，退出重进可继续选择，完成后不重复发放。已有进度的旧存档只补选主角，保留原队伍与资源；完全未游玩的旧默认存档转入完整新手流程。主角与初始选择保存于 `State.journey`，重新探险保留选择。
