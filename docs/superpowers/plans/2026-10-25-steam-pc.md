# Steam PC 实装计划

> 按用户已批准的 PC 互动方案执行；不自建服务器，不发布商店或改动手机规则。

**目标：** Windows 客户端具备真实 Steam 好友结缘、玩家房主合作副本、成绩榜及离线单人试炼。
**架构：** Cocos 原生桥接 Steamworks，PC 独立协议层与确定性副本规则；账号档案与奖励一次性记录共同保存。Steam 不可用时保留单机并明确显示服务状态。
**技术：** 现有 Cocos Creator 3.8.7、TypeScript、C++、Steamworks SDK。
**设计：** [PC设计](../../../pc/README.md#steam互动设计2026-10-25)。

## 分工与检查

- [x] `pc/native/SteamBridge.*`、`pc/game/PCSteam.ts`、Windows构建入口：真实身份、邀请、Lobby、可靠消息、时间、榜单与详情文件；缺失Steam安全降级及实际编译通过。
- [x] `pc/game/PCRaid.ts`：1人试炼/2–4人副本、骰子、仇恨、AOE、候补、回放和排名编码；确定性、非法动作、死亡/换宠、同分与不同人数检查通过。
- [x] `pc/game/PCSocial.ts`：结缘、防重复奖励、好友周期、副本蛋及碎片；原子保存游戏和领取记录。
- [x] `pc/game/PCOnline.ts`：房间协议、共同准备、结果重演、断线中止/重连、榜单；模拟传输17组通过，不能作为Steam真机证据。
- [x] `pc/game/PCOnlineUI.ts`、`PMPCGame.ts`：旅伴/副本/天梯、独立战场、账号档案、输入屏障；720p/1080p/超宽及7组新流程检查通过。
- [x] 个人云档案手动备份、确认恢复、保留双方原文；规则与5组隔离界面检查通过。
- [x] 运行本轮规则/协议与统一PC检查，构建Windows并启动实际客户端，记录边界。
- [ ] 两账号/四客户端真实Steam联机、云及榜单验收。当前官方初始化报ConnectToGlobalUser failed，需要核对应用开发访问；最终侧栏恢复修复尚待原生复验。

## 必须覆盖的故障路径

- 同一场回合/结缘/领奖重复消息不二次结算；迟到旧房间消息不进入新场次。
- 不能用本地payload自报身份；只接受当前Lobby成员，换账号不读入其他Steam账号进度。
- 房主退出、队员超时、异版/不同步均结束未完成排名，不伪造完成或奖励。
- Steam断开和云配额不可用不妨碍本地保存；主线中邀请不直接丢弃当前战斗。
- 一切评分、奖励和历史阵容均绑定同一场次；客户端校验不宣称服务器级反作弊。
