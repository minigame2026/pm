# PM 页面模板标准

依据：用户指定“伙伴”的全屏格式为统一方向。孵化屋、蛋袋、交配、来信已按此实现，当前具体外观仍待用户试玩评价；不要写成已验收。

## 页面路由
| 类型 | 复用位置（PMGame.ts） | 应放的内容 |
|---|---|---|
| 常驻功能全屏页 | `fullPage`、`sectionHeader`、`pageBounds` | 标题、返回、内容区、底部主要操作 |
| 伙伴/蛋/系列选择 | `partnersUI`、`eggShelf`、`bondsUI` | 卡片、选中态、分页、选择后的操作 |
| 等待与领取 | `hatchery`、`breedingUI` | 对象、倒计时、可操作状态、领取/加速 |
| 规则帮助或短确认 | `pageHelp`、`overlay` | 当前需要的规则或后果；不承载整个日常功能 |
| 战斗 HUD | 现有战斗布局 | 独立复用战斗模板，不套功能页的全屏结构 |

## 当前项目视觉参数
- 逻辑宽度 390；高度从 `pageBounds` 获取。顶部暖红色标题栏（`#c95750`）88 高，左上返回；没有副标题时主标题垂直居中。
- 页面底色 `#edf4f5`，卡片白色，选中 `#fff1d6`，底部操作区 `#fffdf5`。
- 内容宽通常 354；三列卡片 112 宽、中心间距 120。主要按钮约 350×48；沿用当前相应功能色。
- 倒计时、状态、按钮基于顶部/底部定位；大屏扩展内容区，小屏不能整体压扁字体和图标。
- 子页返回上一级，顶级功能返回进入前的页面；换页不得重置任务、宠物、计时或选择以外的数据。
- APP列表分页使用 Cocos `PageView` 横向滑动与吸附，保持当前页与相邻页节点；网页/小游戏使用左右按钮翻页，均保留页码。`listItem` 标记分页卡片，`pagePager` 统一组织视口；伙伴列表横滑翻页、纵向拖动换队，不能互相触发。空孵化位整块“＋”卡片可点击选蛋。

## 共享质感与分端动效（2026-10-23）

设计参考：[Pokémon TCG Pocket收藏展示](https://www.pokemontcgpocket.com/ja/howtoplay/collection/)突出收集对象；[Material动效原则](https://m3.material.io/styles/motion/overview/how-it-works)用于反馈与过渡。保留本项目的宠物原画和功能色，不改变玩法与导航。

- `PMUIStyle`统一按钮/卡片绘制和动效参数：纸白卡片、细边、低透明阴影；主次文字保持对比。小状态条、半透明HUD、整屏底板保持平面，不能全部装饰成浮起的卡片。
- 移除所有普通可用按钮的持续闪动描边；保留营地主操作/待领取等已有定向提醒。按下才给短反馈；触区仍至少48物理像素。
- 网页/小游戏：按下缩至97.5%，45ms进入/100ms释放；页面140ms淡入，不位移、不回弹。
- APP：按下缩至96.5%，50ms进入/160ms释放，最多101.2%轻回弹；功能页/弹窗220ms淡入并移动10逻辑像素。整屏营地/地图/伙伴只淡入，以免背景和触点错位。以上时长是本项目参数，不是参考产品的实测值。
- 同一路由内的选宠、翻页、数字更新不重新播入场动画；页面离开停止旧动画。按下取消恢复原比例；不等待完整释放才执行操作，重复点击受现有防连点保护。
- 共用布局、存档和规则；原生APP通过`sys.isNative`选择表现配置。系统减少动态效果开启时，这组按压/入场动画关闭。
- 静态绘制复用原Graphics，不新增贴图、粒子或实时模糊；短动画仅在交互/切页发生。浏览器模拟APP参数不等于原生真机性能验证。

检查组`ui-polish`负责表现参数、交互生命周期与代表截图；相关回归使用`ui-comfort`、`app-pages`、`home-motion`，不默认运行全项目。

## 每次实际需要的状态
选择卡片 → 选中态 → 一个主要操作。等待中显示倒计时；资源不足显示灰色与简短原因；可领取时突出按钮；空列表给出一个去向。只实现本次功能需要的状态。

## 文字预算
标题说明所在位置；卡片显示对象、品质和必要数值；按钮用短动词。长概率/遗传规则收进“?”。消耗父母、花费资源等后果必须在行动前可见。数字要带足够语义，避免生造难懂的复合图标。

## 地图预览模板

12地区按钮固定两行、每行6个；图鉴“全部”放在页头，避免挤占地区网格。标题、属性、两排宠物图与名称、底部说明各有独立区域。图高从实际内容高度计算，不能固定向下偏移名称挤占下一行。短屏缩减标题区并限制说明换行；长说明进帮助，不叠在立绘上。`map-layout`以实际节点边界检查12地图及图鉴地区，覆盖390×650、320×568、390×844和英文/德文/阿拉伯文/俄文/泰米尔文。

## 最小检查
先用 `ui` 或 `social` 检查组。查看本次实际生成的 390×844 与 320×568 截图，检查遮挡、挤压、留白和返回路径；截图生成成功不等于视觉通过。不要因为某一次引擎控件故障而扩写整套通用规范。
