# 骰子宠物精灵：当前游戏设计

基线：2026-10-20。数值执行源 [PMModel.ts](../assets/scripts/PMModel.ts)，公式见 [BALANCE](BALANCE.md)，限制见 [STATUS](STATUS.md)。

## 核心循环

封面→选择主角→三选一初始R伙伴→营地→选地图→选敌/选伙伴→随机点数战斗→奖励/巢穴→继续或通关结算→营地孵化、编队、交配与好友结缘。

已有探险时，封面“开始游戏”直接接续；失败/通关恢复结算页。主动撤退结束本次探险，体力不退。一次地图入场扣5体力，草叶海岸10场战斗算一个大关。九张地图均为10层，依次解锁，进入选图默认选中已解锁的最新地图。

## 页面与操作

| 页面 | 主要内容 | 数据/操作约束 |
|---|---|---|
| 封面 | 标题、副标题、开始游戏 | 自动判定开局或恢复，不加重复入口 |
| 营地 | 主角/体力、探险、伙伴、孵化屋、交配屋、来信、图鉴 | 六时段背景；体力30上限，每2分钟+1 |
| 地图 | 九地图横滑、宠物/层数/蛋预览 | 未通前图不解锁；新探险扣5体力 |
| 选敌 | 敌我同构名称/攻击/HP、单项奖励、三槽选宠 | 免费刷新1次，其后激励视频；BOSS不能刷新；交配候补置灰 |
| 战斗 | 对位攻击、HP，治疗/力量/防御/攻击四键 | 药水不推进回合；攻击/防御推进回合；已用或空库存变灰 |
| 奖励 | 普通/精英单项；攻击/治疗点数组新旧二选一 | 确认后恢复20%最大HP；精英接寻蛋，BOSS直接寻蛋 |
| 巢穴 | 主角半身、蛋、精英2次/BOSS3次翻找 | 用尽默认最高品质，同档取最早；阿岚20%额外蛋 |
| 结算 | 胜利通关/失败，返回营地 | 保留收藏与获得的蛋；不退体力 |
| 伙伴 | 独立个体、三槽拖放、横滑列表 | 重复宠物不同UID；换队保持HP比例 |
| 图鉴 | 162个独立宠物条目、地区/属性/拥有筛选、独立宠物/克制详情 | 拥有计数不是历史收集记录；不能直接获得宠物 |
| 孵化屋/蛋袋 | 两槽、整卡＋选蛋、倒计时、领取、视频−30分钟 | 校时失败暂缓结算；不显示能量 |
| 交配屋 | 雌雄各一、30分钟、领取蛋 | 当前出战不在列表；领取永久消耗父母，必须提示 |
| 来信 | 导入/分享来访码、互动、结缘系列 | 访客不能编队/交配；用自有蛋结缘 |
| 设置 | 音乐/音效、右上× | 探险右上为撤退/回家 |

## 战斗与长期成长

- 每回合预先确定敌我点数和药水倍率；界面与执行共用结果。力量×2/3/4概率50/40/10%，治疗×1/2/3概率50/40/10%。
- 18种单属性双方独立查询，伤害倍率1.5/1/0.75/0.5；固定技能加伤、毒、治疗和护盾不乘属性。完整顺序见BALANCE。
- 每只宠物按UID独立保存本次探险HP、生命上限加成及攻击点数。奖励只影响领奖时出战个体；药水库存和治疗数组仍全队共用。出战阵亡依次由第一、第二候补接替，本次探险内不能复活/再次出战；全部可战队员阵亡才失败。重新探险恢复生命并清除本局成长。
- 自然孵化每只一个品质对应技能；交配最多六种自动技能。重复保留新个体，性别各50%。R/SR/SSR为独立命名与图片的三形态，无原地进化按钮。
- 初始只有选中的一只；以后只能通过孵化获得新宠物。交配产蛋，领取消耗父母；好友解锁系列并用自己的蛋定向孵化，不复制好友个体。

## 状态与恢复

encounter→battle→reward/nest/lost；reward→encounter/nest；nest→eggClaimed→encounter/won。screen是路由，phase是探险状态，不能用营地画面覆盖保存的战斗。

保存完整动作结果后再播放动画；动画中退出恢复结算后的血量、药水及随机种子，不重演伤害。领奖与孵化领取保持幂等。见 [架构与存档](TECHNICAL.md)。
